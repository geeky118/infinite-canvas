# 执行计划

`active/` 存放进行中的计划，`completed/` 存放已经完成并交接的计划。

以下任务需要创建或更新执行计划：

- 同时影响前端、后端、文档或部署配置中的多个模块。
- 需要分阶段处理，且下一次对话必须能接着做。
- 涉及数据库结构、画布核心数据结构、导入导出、鉴权、扣费、模型渠道或部署流程。
- 用户明确要求“继续之前任务”“按计划执行”“整理方案再做”。

文件名建议：

```text
YYYY-MM-DD-short-task-name.md
```

计划应包含：

- 目标和范围。
- 已知约束，尤其是 `AGENTS.md` 中的项目规则。
- 涉及文件和模块。
- 分步执行清单。
- 验证方式和未验证原因。
- 当前决策、风险和待用户确认事项。

任务完成后，如果计划仍有长期参考价值，移动到 `completed/`；如果只是短期草稿，可在交接后删除。
