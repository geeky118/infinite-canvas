# 管理端营销奖励与兑换码

## 背景

管理端需要增加营销能力：配置新注册用户奖励、每日领取点数、订阅方案，以及批量生成兑换码。用户端需要支持输入兑换码兑换点数或订阅卡。

## 范围

- 后端新增营销配置、订阅方案、兑换码数据结构与接口。
- 注册、Linux.do 首次登录注册、每日领取、兑换码兑换统一写入算力点流水。
- 管理端新增营销页面，支持配置奖励、维护订阅方案、生成和查看兑换码。
- 用户端新增兑换入口与每日领取入口。
- 更新数据库与待测试文档。

## 非范围

- 不新增支付系统。
- 不做旧数据兼容迁移。
- 不执行构建或测试。

## 实施步骤

1. 梳理现有用户、设置、算力点流水和后台页面结构。
2. 增加后端模型、仓储、服务、处理器和路由。
3. 增加前端 API 封装和管理端营销页面。
4. 增加用户端兑换/每日领取入口。
5. 更新文档。

## 验证

- 按项目规则本次不运行构建或测试。
- 需要用户后续在后台验证配置保存、订阅创建、兑换码生成与兑换状态流转。
