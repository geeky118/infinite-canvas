# 用户画布与模型配置持久化

## 目标

- 登录用户的画布项目不只保存在浏览器本地，需要同步到服务端。
- 登录用户的模型配置不只保存在浏览器本地，需要同步到服务端。
- 登录用户的“我的素材”不只保存在浏览器本地，需要同步到服务端；提示词中心是后端数据，加入“我的素材”的提示词随素材同步。
- 未登录用户继续使用当前浏览器本地持久化体验。

## 范围

- 后端新增用户级 JSON 数据存储，按用户和数据域保存。
- 前端新增用户数据 API 封装。
- 画布 store、配置 store 与素材 store 在登录态下自动拉取和保存服务端数据。
- 更新数据库和进度文档。
