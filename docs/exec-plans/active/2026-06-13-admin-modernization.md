# 管理后台现代化改造

## 背景

现有管理后台为扁平菜单和分散页面，缺少现代后台常见的信息架构、统计首页、权限管理、菜单管理和财务视图。目标是使用 Ant Design 体系规范化后台，并在完成后走本地 Docker 测试、服务器发布和提交。

## 范围

- 提交修改前快照。
- 管理后台统一为现代化侧边栏分组、面包屑/标题区、统计首页。
- 新增或规范化权限管理、菜单管理、统计、营销、财务、用户、素材、提示词等后台模块。
- 使用 Ant Design / ProTable 延续现有技术栈。
- 补充必要的后端配置模型或接口。
- 远程提示词定时同步默认关闭，避免启动后批量拉取远程源占用 SQLite 写锁；保留后台提示词页手动同步。
- 完成后本地 Docker 容器标准测试，再提交修改后 commit 并发布服务器。

## 第一阶段

1. 建立管理后台模块注册表和分组菜单。
2. 改造后台 layout，支持业务域分组、页面标题和次级说明。
3. 新增统计首页。
4. 新增权限管理、菜单管理和财务页面的可持久化基础版本。
5. 保持现有用户、素材、提示词、营销和系统设置页面可访问。

## 验证

- 前端构建或 Docker 测试前先做代码级检查。
- 本地 Docker 容器启动后验证后台关键路由非空。
- 发布服务器后验证线上容器、健康检查和后台入口。
