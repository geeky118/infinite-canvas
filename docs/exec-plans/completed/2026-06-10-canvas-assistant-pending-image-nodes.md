# 画布助手生成中图片节点体验优化

## 目标

- 画布助手规划好图片任务后，立即在画布空白位置创建“生成中”的图片节点。
- 图片生成成功后复用这些占位节点原地回填，不再成功后才插入节点。
- 助手生成图片节点按真实图片宽高比例显示，默认固定图片节点高度，按比例调整节点宽度。
