# 待测试

- 用户端品牌视觉刷新：顶部导航、首页、登录页、画布库、生图工作台、视频创作台、提示词中心、我的素材和画布主题改为新的蓝色主色体系，并使用新的彩色 Logo；新增用户端设计规范文档。需要验证日间/夜间模式下页面背景、面板、按钮、筛选标签、弹窗、滚动区域和移动端导航都正常，文字不溢出，核心入口点击可达。
- 管理后台新增并增强“营销管理”：可设置新注册用户奖励点数和每日领取点数，维护订阅方案，批量生成点数或订阅兑换码，生成后可直接复制本批次兑换码；兑换码列表支持按类型、使用状态、批次 ID 和关键词筛选，并展示兑换码类型、批次、使用状态、使用用户和使用时间；后台总览和统计页补充启用订阅数、未使用兑换码、点数码和订阅码等运营指标。用户头像菜单新增“兑换中心”，可领取每日点数、输入兑换码兑换点数或订阅；注册奖励、每日领取、点数兑换和订阅兑换都会写入后台可审计流水。需要验证后台配置保存、订阅新增/停用、兑换码生成后复制、按类型/状态/批次筛选、兑换码一次性使用、每日领取一天只能领取一次、用户余额/订阅状态刷新、算力点日志类型展示和后台统计数字都正常。
- 管理后台算力点日志的用户列改为展示用户邮箱，搜索支持按用户邮箱查找；手动新增或编辑日志时填写用户邮箱，后端会解析为真实用户并继续保存到 `credit_logs.user_id`。需要验证邮箱为空的旧账号会用用户名兜底展示，填写不存在的邮箱会提示失败。
- 提示词中心、画布提示词库和管理后台提示词封面改为通过 `/image-proxy` 展示远程图片，空封面或加载失败的封面继续回退到站点 Logo；公开提示词列表只返回已有提示词的分类，用户端分类/标签没有实际选项时不再显示筛选行。远程同步新增 YouMind AI Image Prompts、NeXra、NanoBanana Trending、Awesome AI Image Prompts、Ultimate GPT Image & Nano Banana、Cliprise Product Photography、aitools12 GPT Image 2 等图片案例提示词源，并在正式入库前按提示词正文做同源和跨源去重，大源写入使用批量插入；远程提示词定时同步默认关闭，后台手动同步入口保留。需要验证 GitHub raw 等远程提示词封面在普通用户页面、画布弹窗和后台详情中都能正常显示，空分类不会再出现在画布提示词库中，手动同步新增源后不会出现重复提示词或 SQLite 批量写入失败，服务启动后不会自动批量同步远程提示词。
- 首页提示词库和提示词列表改为优先展示有封面图的提示词；首页提示词卡片点击后打开提示词详情弹窗，详情弹窗新增“去试试”，会跳转到 `/image` 生图工作台并回填提示词，自动识别提示词里的尺寸、质量、张数，并在可用图片模型中按 GPT Image、Nano Banana、GPT-4o、Seedream 等提示词来源匹配模型。需要验证首页优先显示有图提示词、详情弹窗内容、复制提示词和“去试试”跳转回填都正常。
- 用户进入画布时默认打开右侧助手面板；助手底部取消手动“对话/生图”模式切换，仅保留图片模型和图片参数两个图标入口，发送后由助手根据输入自动判断文字对话或图片任务；同一个画布项目内可新增多个助手对话，对话可归档、从归档恢复或删除，文本对话会保存结构化会话记忆，并在长对话中使用会话记忆加最近消息作为上下文；记忆会先本地兜底，再由文字模型压缩为摘要、偏好、事实和未解决问题；登录用户的会话记忆会跟随画布项目通过 `/api/v1/user-data/canvas` 保存到数据库 `user_data.payload`。需要验证进入画布后助手默认展开，底部不再出现文字/图片模式切换，图片模型和图片参数图标可正常打开，普通提问仍走文字对话，图片生成/编辑/拆分请求和“用刚才的提示词生成图”仍会自动走图片任务；还需要验证切换不同画布项目后助手会话互不串用，归档不会删除生成图片，删除才清理对应资源，长对话不会无限携带全量历史，登录后刷新或跨设备加载仍能恢复会话记忆。
- 画布顶部右侧入口顺序改为日间/夜间切换、项目系统提示词、剩余点数、用户信息，并在画布内隐藏版本号和配置入口；主页顶部隐藏版本号但保留配置入口。需要验证画布页和主页顶部入口顺序、显示状态和点击行为都正常。
- 画布助手的图像任务会根据用户输入自动路由：发送后会先由文字模型做结构化意图分类，结合最近对话和选中节点判断为普通问答、图片分析、图片生成、图片编辑或图片拆分，模型路由不可用或返回异常时才使用本地规则兜底；框选多个图片后可直接分析；要求生成、创建、绘制、修改图片时会走图像生成或图像编辑接口；要求拆分、拆解、提取元素、不同姿势、多张独立图片、多页面 UI 设计时会先由创意任务编排智能体分析用户意图，再输出纯 JSON 任务计划，为子任务分配执行角色（如 UI 设计师、摄影导演、风格分析师、元素拆分师、图片编辑师），最后把每个子任务的 `execution` JSON 作为实际提示词下发给生图/修图接口。带参考图时，“改为/换成/换一个/缩短/全身/半身/俯视/姿势/动作/构图/角度/服装/背景”等视觉变化会稳定识别为图片编辑任务，并保留对应参考图，不再落到普通文字回答只输出改图提示词。多交付物会按每个任务 1 张图逐项生成，避免把三张图、多个姿势或多个页面合成到同一张图里；多张参考图需要合成、融合或做成同一张最终图时会保持单任务并携带全部参考图，只有用户明确要求每张参考图分别处理时才按参考图拆分；单一交付物才允许用任务 `count` 生成候选图，且任务 `count` 会和 `execution.output.count` 保持一致；如果上游意外多返回图片，多任务执行层只采用当前子任务目标张数。参考图“其他场景/不同场景”会拆成中性日常场景任务，图片编辑遇到内容策略或安全拒绝会自动改写成安全提示词重试；连续生图时，除非用户明确说“这张/参考图/保持一致/修改/分析/拆分”等，否则不会把上一轮残留选中图片带入新生图请求；如果上一轮刚由助手生成或编辑了图片，用户没有重新选中图片但直接输入“镜头拉近一些”“换一个姿势”“改为全身图”等短指令，会自动把上一张助手图片作为参考图走图片编辑。发送后会先把用户消息和当前任务状态显示出来，再执行模型路由、参考图读取和任务规划；单张参考图的短改图指令会跳过额外的文字模型路由和视觉任务规划，直接进入图片编辑准备，减少一直转圈的等待感。图片模式会识别“用这个提示词/上面的提示词/刚才的提示词”等上下文指代，自动取最近一条助手文字回答作为实际生图提示词，并叠加用户当前补充要求。助手规划好图片任务后会立即在画布空白位置创建“生成中”图片节点，生成成功后原地回填结果图；助手图片节点固定默认高度并按真实图片比例调整宽度，避免节点框和图片比例不一致；画布图片节点改为直角显示且不再显示“图片1/图片2”资源序号角标；刷新页面后，对话里的助手图片预览和再次插入会通过 `storageKey` 重新恢复，不再依赖已失效的旧 `blob:` 地址；如果接口已经返回图片但本地保存或自动插入失败，对话中仍保留已返回图片并提示可重试添加，不再把整条结果覆盖为“请求失败”。需要验证单图、多图、已有节点密集区域、图片节点直角和无序号角标、规划后生成中占位节点、成功后原地回填和按比例显示、刷新后对话图片预览、多参考图合成单任务、多参考图逐张处理、图片编辑、单张参考图短改图发送后能立即显示任务状态且更快进入编辑、图片分析不触发生图、文字对话生成提示词后切图片模式生图、上一轮助手生成/编辑图后不选中图片直接说镜头拉近/换姿势仍走图片编辑、不同姿势写真、首页/商品详情页 UI 设计拆分、设计风格分析后生图、元素拆分生图、连续生图残留选择过滤和手动再次插入都正常。
- 画布系统提示词改为项目级设置，新建画布会默认打开设置弹窗，也可从画布顶部右侧的“项目系统提示词”入口编辑；弹窗放大后支持 Markdown 编辑/预览，并可调用文字模型进行 AI 提示词优化；同一账号下不同画布项目会分别保存自己的系统提示词，画布生成、配置节点生成、图片编辑/重试、反推提示词和右侧助手都应读取当前项目的提示词；需要验证新建画布默认弹窗、Markdown 预览、AI 优化只调用文字模型、切换项目后提示词互不串用，登录用户跨设备同步后仍按项目生效。
- 登录用户的画布项目、模型配置和“我的素材”会通过 `/api/v1/user-data/canvas`、`/api/v1/user-data/ai-config`、`/api/v1/user-data/assets` 保存到服务端；`canvas` 域会保存完整 `{ projects }`，每个项目内包含节点、连线、助手对话 `chatSessions`、当前对话 ID、项目系统提示词、视口和外观设置。登录后优先读取服务端数据，服务端无数据时会把当前本地数据作为首次云端版本保存；没有 URL 配置参数的普通进入会默认使用后台云端渠道，带 `baseUrl`/`apiKey` 参数进入时才会自动打开配置弹窗并导入本地直连配置，避免首页提示词跳到生图工作台时停在空的本地直连配置。未登录用户继续使用浏览器本地存储；画布库和画布详情页会等待云端项目数据完成加载后再显示或判断项目不存在，避免换浏览器直达画布详情时提前跳回列表。画布云端自动保存会合并短时间内的连续变化，避免生成图片和助手对话期间频繁上传整份画布数据，并在页面隐藏、关闭或同步组件卸载前主动提交待保存数据；`user_data.payload` 在 MySQL 下会校正为 `LONGTEXT`，避免长画布 JSON 超出普通 `TEXT` 容量。提示词中心本身来自后端提示词表，用户加入“我的素材”的提示词会作为文本素材同步；需要验证新账号首次登录后配置弹窗默认显示后台云端渠道模型，从首页提示词“去试试”进入生图工作台后可直接读取后台模型；还需要验证带 `baseUrl`/`apiKey` 参数进入时会打开配置弹窗并切到本地直连，同一账号跨浏览器/跨设备登录后画布节点、连线、系统提示词、助手对话、模型配置、素材库和已保存提示词能同步，退出登录后不会继续写入服务端，生成期间不会密集提交 `/api/v1/user-data/canvas`，长对话或节点较多的画布保存不报错。
