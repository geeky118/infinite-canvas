# 用户端设计规范

## 品牌资产

- 主 logo 使用 `web/public/logo.png`，小尺寸场景使用 `web/public/logo-icon.png` 或 `web/public/logo-64.png`。
- 用户端导航、登录、首屏和空状态优先直接展示彩色 logo，不再使用纯色 SVG mask。
- 首屏产品视觉和提示词缺省封面统一通过 `web/src/constant/env.ts` 的 `BRAND_HERO_IMAGE_URL` 引用 COS 上预压缩的 WebP 资源（默认 1536x1024，~120KB），本地不再保留同一份资源，避免重复打包。
- logo 周围需要保留至少 0.25 倍图标宽度的留白，小尺寸显示时保持圆角和轻量阴影。

## 色彩

- 主色：`#0A84FF`，用于主按钮、选中态、关键链接和导航激活态。
- 深色主色：`#52B5FF`，用于夜间模式主按钮、选中态和关键文字。
- 辅助色：`#24D1FF`，用于渐变、强调线和轻量装饰。
- 日间背景：蓝白渐变，页面底色以 `#F5FAFF`、`#EAF4FF` 为主。
- 夜间背景：深蓝黑，页面底色以 `#061320`、`#0B1724` 为主。
- 禁止用户端正式页面继续以大面积 stone/slate 中性灰作为主视觉。

## 页面

- 用户端页面优先使用 `brand-app-bg` 作为页面背景，列表、工作台和登录面板使用 `brand-panel`。
- 首页首屏要直接呈现产品名称、核心入口和真实功能模块，不放模板说明、配置来源或实现提示。
- 首页右侧优先使用真实品牌视觉资产或产品化画布模块，不使用单纯步骤列表作为主视觉。
- 工作台类页面保持高效密度，左侧记录、中央输入、右侧结果的结构不变，只更新品牌化背景、边框和选中态。
- 移动端页面保持首屏入口清晰，按钮和卡片文字不得溢出或互相遮挡。

## 日夜模式

- 日间模式使用白色半透明面板、蓝色轻边框和浅蓝网格背景。
- 夜间模式使用深蓝半透明面板、低透明度天蓝边框和高对比文字。
- 新增用户端颜色应优先使用全局 CSS 变量、`brand-*` 工具类、`getAntThemeConfig` 或 `canvasThemes`。
- 不要在单个页面硬编码一套独立的黑白主题分支，除非该页面已有局部样式必须覆盖。

## 组件状态

- 主按钮使用品牌蓝，hover 不改变布局尺寸。
- 标签筛选选中态使用实心品牌蓝，夜间模式使用亮蓝底和深色文字。
- 卡片 hover 只允许轻微位移、阴影或边框增强，避免大幅动画影响列表扫描。
- 画布工具栏继续保持极简扁平，不额外增加厚重卡片、胶囊背景或解释性标签。

## 文案

- 页面文案保持中文，表达直接面向正式用户。
- 禁止出现解释性占位、模板名、实现说明、调试提示和“从这里开始”类产品说明型 copy。
- 空状态和加载态只说明当前状态与可执行动作，不解释后台配置或实现方式。
